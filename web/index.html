VI
Method, honestly
What each number means and what it cannot tell you.

  

    
The oracle
For built-in CG-Lang the oracle is a second implementation of the language. For grammar targets it is an Earley parser, which accepts exactly the grammar’s language. A disagreement is a bug signal: a candidate for investigation, never a proven defect.

    
Equal budgets
Every approach executes the same number of tests and shares the same first tests. The rest are blind mutation, mutation steered by compiler feedback, or AI proposals steered by the same feedback.

    
Limits
The C++ target is a substantial subset, not the full ISO grammar. Coverage metrics describe diversity of behaviour, not guaranteed defect-finding power, and a few trials give descriptive statistics only.
