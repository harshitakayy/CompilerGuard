Playground

Write a CG-Lang program and compile it. The compiler's result is checked against an independent reference implementation, so wrong answers are caught, not just crashes.

Fuzz campaign

Generates valid programs from the grammar, mutates them into invalid ones, adds stress cases, then keeps mutating whatever reached new compiler behaviour. Every bug is shrunk to a minimal reproducer.

AI-guided tests

The compiler's error patterns are sent to an AI model, which writes new test programs aimed at nearby edge cases. Those tests run against the compiler, the new errors go back to the AI, and the loop repeats.

Report

The report covers the most recent campaign and AI run. If you have not run one yet, a default campaign is run for you.
